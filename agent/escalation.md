# Правила эскалации — _Сбор и сверка данных по отчётному событию_

> З6. Когда агент **останавливается и зовёт человека**. Работа без проверки несёт риск: лучше лишний раз спросить, чем незаметно ошибиться.

## Условия остановки (агент зовёт меня, если…)
- Уверенность в ответе ниже порога: расхождение между источниками по числовой метрике, которое не удаётся объяснить (пример — EPS на Nebius 2К26, два значения из разных агрегаторов).
- Цена ошибки высокая: неподтверждённый вывод подан как установленный факт — главная ошибка функции, по аналогии с `function-card.md` из примера «Радар».
- Данных не хватает / противоречие в источниках: ключевая метрика (Revenue, EBITDA, EPS, Margin, Capex или гайденс) не найдена ни в одном разрешённом источнике после повторной попытки.
- Действие необратимо: неприменимо напрямую — у агента v1 нет доступа к публикации (ни в БД, ни в Telegram, см. `agent/contract.md`), поэтому необратимых действий физически не совершает. Ближайший эквивалент — «включить непроверенное число в датасет без пометки»: тоже недопустимо, трактуется как остановка.
- Выходит за границы контракта: запрос на оценку стоимости компании или инвестиционную рекомендацию (buy/sell, целевая цена) — не входит в функцию v1.1, агент отказывается и ссылается на `agent/contract.md`. (Интерпретация результатов и реакции рынка — с 2026-08-25 часть функции, см. `agent/contract.md` v1.1 — сама по себе эскалации не требует, если основана на найденных источниках.)

## Пороги
| Ситуация | Порог | Что делает агент |
|---|---|---|
| Расхождение между источниками по метрике | любое расхождение без установленной причины | не выбирает, не усредняет; помечает явно, продолжает остальной сбор, финальное решение — владельцу |
| Ключевой источник недоступен (call/release/letter/presentation) | после одной повторной попытки (~через час) | останавливает попытки по этому источнику, сообщает владельцу, остальные источники продолжает собирать |
| Новый тип компании без playbook в `core.md` | playbook отсутствует для этого типа | не придумывает акценты сам — их в этой функции и не делает; явно помечает «playbook не определён» на будущее |
| Сумма/ставка | неприменимо — функция не работает с деньгами напрямую | — |
| Запрос выходит за функцию (оценка стоимости/инвестрекомендация/публикация) | всегда | отказывается, ссылается на `agent/contract.md` |

## Что агент делает при остановке
1. Не выполняет спорное действие — не подставляет число, не выбирает между расходящимися источниками, не публикует и не интерпретирует.
2. Готовит черновик датасета целиком (кроме спорного пункта) + явное объяснение, что именно не сходится или не найдено.
3. Пишет мне: сейчас — явной пометкой в `data-collection.md` (⚠️) и сообщением в текущем диалоге; отдельный канал (Telegram/почта) не подключён — агент работает не автономно, а в сессии со мной.
4. Ждёт решения; решение → правка в `memory/core.md` (журнал «ошибка → правка»).

## Точки сохранения (на случай сбоя)
**Где агент сохраняет состояние, чтобы не повторять/не терять шаг:** каждый найденный первичный источник сохраняется в `Reporting/<год>/` сразу после скачивания, а не в конце прогона — если прогон прервётся на середине, уже скачанные документы не теряются и не запрашиваются повторно при следующем запуске.
