# Подготовка до занятия 1

Цель подготовки — прийти на занятие с работающими инструментами, клонированным репозиторием и материалом своего бизнеса. Файлы курса уже разложены правильно: собирать репозиторий вручную не нужно.

## 1. Проверь инструменты

Нужны:

- Git;
- Node.js 20.11 или новее и npm;
- Claude Code и учётная запись Anthropic;
- редактор кода и терминал.

Выполни из терминала:

```bash
git --version
node --version
npm --version
claude --version
```

Все четыре команды должны завершиться без ошибки. Если одна из них не работает, напиши ведущему до занятия.

## 2. Проверь репозиторий

Открой терминал в корне этой папки и запусти Claude Code. Попроси агента:

> Перечисли файлы в `memory/` и покажи заголовок раздела 1 в `blueprint.md`.

В ответе должны быть `identity.md`, `core.md` и раздел «Гипотеза OME». Не заполняй эти файлы заранее: мы сделаем это вместе на занятии.

## 3. Подготовь материал для практики

1. Прочитай праймер OME, который выдал ведущий.
2. Выбери один реальный бизнес или проект, с которым будешь работать весь интенсив.
3. Выбери основной и дополнительный тип участника в праймере.
4. Запиши 5–7 повторяющихся задач, которые отнимают время или раздражают.

Не добавляй в репозиторий пароли, ключи, данные клиентов и другие сведения, которые нельзя отправлять поставщику модели.

## 4. Что открыть на занятии

- упражнения занятия — их выдаёт ведущий;
- `memory/identity.md`;
- `memory/core.md`;
- раздел 1 `blueprint.md`.

## Что не трогать

- Условия зачётов и табель — их ведёт ведущий. Ты их не редактируешь, а сдаёшь по ним.
- `examples/` — эталоны для сверки. Их не заполняешь, а смотришь, как выглядит готовое.
- `CLAUDE.md` — трогать не нужно: он указывает Claude Code читать файлы из `memory/`. После заполнения памяти попроси агента перечитать `identity.md` и `core.md` или начни новую сессию из корня репозитория.

## Если застрял

- Не успел поставить инструменты к занятию — предупреди ведущего до начала. На занятии работай в паре, после встречи закончи установку по этому файлу и выполни четыре шага практики у себя.
- Не понимаешь, **что** заполнять и когда, — найди текстовую метку занятия `З_` в шаблонах.
- Не понимаешь, **как** заполнять, — рядом с каждым полем есть подписи «Подсказка», «Пример» и «Антипример». Полные образцы — в `examples/`.

## Готово, если

- Claude Code запускается из корня репозитория;
- агент видит оба файла в `memory/` и раздел 1 `blueprint.md`;
- праймер прочитан;
- выбран реальный бизнес;
- список из 5–7 повторяющихся задач готов.

Проверяющий агент понадобится только после занятия. Адрес его репозитория и закреплённую версию даст ведущий.
