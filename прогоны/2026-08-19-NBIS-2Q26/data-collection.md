## ⚠️ Найдено расхождение — по правилу core.md, не выбираю сам, выношу тебе

По EPS два разных значения из двух источников поиска:
- Источник A (агрегатор новостей через веб-поиск): факт **-$0,12**, консенсус **-$0,69**, «beat by $0,57».
- Источник B (сам транскрипт investing.com, Q&A-блок): adjusted EPS **-$0,68**, «beat forecast of -$51,46».

Цифра «-$51,46» по консенсусу выглядит как явная ошибка/артефакт разбора текста (нереалистичное значение). Но и то, что источники A и B расходятся даже по факту (-$0,12 против -$0,68) — не объяснено. **Не подставляю ни одно из значений в итог — это твоё решение, какой источник считать надёжным для EPS**, либо оба откладываем как неподтверждённые до проверки по самому PDF-релизу.

## Обновление после разбора с владельцем: где на самом деле лежали «ненайденные» данные

Первая версия этого прогона использовала только транскрипт звонка (investing.com) — это была ошибка сузить сбор до одного типа документа. Владелец указал на это прямо: раз собирали и пресс-релиз, и презентацию, их и нужно было прочитать, а не только звонок.

Дособрал: **Cash $8млрд, secured debt $775млн (июль, SOFR + 2.50%), продажа 12,7млн акций по $223,6, gross proceeds $2,8млрд** — всё это нашлось не в транскрипте, а в официальном "Letter to shareholders" за 2К26 (страница "Capital requirements"). Файл сохранён локально и сверяем:
`OME Examples/Nebius (NBIS US)/Reporting/2026/NBIS letter 2Q26.pdf`

Вывод для процедуры (на будущее, в `agent/sop.md`): для сбора данных по одному отчётному событию обязательны минимум ТРИ документа, а не один — call transcript (нарратив, Q&A) + пресс-релиз (факт-таблицы) + shareholder letter (гайденс, cash/debt, капекс). Один транскрипт не покрывает баланс и финансирование.
