# Эталоны для сверки

> Не заполняй эти файлы — смотри, как выглядит готовое. Бизнесы вымышленные, цифры реалистичные; твои значения будут другими. Важна **степень конкретности**, а не сами числа.

- `expert.md` — продуктированный эксперт
- `agency.md` — соло-агентство
- `saas.md` — Micro-SaaS
- `bad-vs-good.md` — «плохо → хорошо» для 4 ключевых мест: гипотеза OME, ограничивающая функция, контракт агента, метрика до/после
- `report-style-templates.md` — не курсовой эталон OME, а лекала стиля/глубины для интерпретационной части реальных отчётов агента (добавлено 2026-08-25, вне рубрики курса)

> Подсказка. Сверяйся, когда поле в твоём файле получается общим («помогаю клиентам», «стало удобнее»). Пример показывает нужный уровень конкретности.
